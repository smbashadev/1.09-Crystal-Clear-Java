# ☕ Java Introduction — Basic Information 

Let's understand each point as if we're telling the **story of how Java came into existence**.

---

## 1. Author — James Gosling 👨‍💻

**James Gosling** is widely known as the **father of Java** because he led the team that developed Java.

Think of it like building a new car:

```text
James Gosling
      ↓
Led Java's development
      ↓
Java was created
```

So remember:

> **James Gosling → Father of Java**

---

## 2. Vendor — Sun Microsystems 🏢

Java was originally developed at **Sun Microsystems**.

Think:

```text
James Gosling + Development Team
              ↓
       Sun Microsystems
              ↓
            Java
```

So:

> **Sun Microsystems → Original company behind Java**

Later, Sun Microsystems was acquired by **Oracle**, which became the steward of Java.

---

## 3. Project Name — Green Project 🌱

Before Java became Java, it was developed as part of a project called the **Green Project**.

Think of it like:

```text
Green Project
      ↓
Development of a new language
      ↓
Oak
      ↓
Java
```

So:

> **Green Project → The project under which the language was initially developed**

---

## 4. Initial Name — Oak 🌳

Java was **originally called Oak**.

Why Oak?

The story commonly told is that **James Gosling had an oak tree outside his office**, which inspired the name.

So:

```text
Initial name → Oak
```

Later, the name was changed because **"Oak" was already associated with an existing trademark**.

---

## 5. Present Name — Java ☕

The language was eventually renamed **Java**.

The name is commonly associated with **coffee**, which is why you often see the coffee-cup symbol ☕ associated with Java.

The important sequence is:

```text
Green Project
      ↓
     Oak
      ↓
    Java
```

### 🧠 Easy memory trick

> **Green → Oak → Java**

---

# 6. Type — Open Source and Free Software

Your notes say:

> **Open source and free software**

There is an important historical distinction here.

Java today has **open-source implementations**, most notably **OpenJDK**, and Java is available under open-source licenses.

But it is not quite accurate to describe the entire history of Java simply as "Java was always open source and free software."

### Think of it this way:

```text
Java
  ↓
Open-source Java implementations
  ↓
OpenJDK
```

**OpenJDK** is the open-source reference implementation of the Java platform.

Also, "free" can mean different things:

* Free to download/use under particular terms
* Open-source source code
* Different JDK distributions may have different licensing/support terms

So for an interview, a safer statement is:

> **Java has open-source implementations such as OpenJDK, while specific JDK distributions can have their own licensing terms.**

---

# 7. Initial Version — JDK 1.0

The first major public release of Java was:

> **JDK 1.0**

It was released in **1996**.

Remember:

```text
Java
 ↓
JDK 1.0
 ↓
First major public JDK release
```

### What is JDK?

**JDK = Java Development Kit**

It provides the tools needed to **develop Java programs**, including the Java compiler and other development tools.

---

# 8. Present Version Mentioned in Your Notes — JDK 1.8

Your notes mention:

> **Present Version — JDK 1.8**

But this is **not the current Java version**.

**JDK 1.8 = Java 8**, released in 2014.

It remains extremely important because many educational materials, existing applications, and interviews still discuss Java 8.

But today, there are much newer Java releases.

So keep these two ideas separate:

```text
Your notes:
JDK 1.8 → Java 8

Actual current Java ecosystem:
Much newer JDK versions exist
```

### Important

Don't say in a current interview:

> "JDK 1.8 is the present version of Java."

Instead:

> **"JDK 1.8 refers to Java 8, an important long-term-support-era Java release, but it is not the latest Java version."**

---

# 9. Objective — Develop Any Kind of Application

The basic objective of Java was to provide a language/platform that could be used to develop **different kinds of applications**.

Think:

```text
                 Java
                   ↓
        ┌──────────┼──────────┐
        ↓          ↓          ↓
      Web       Desktop    Enterprise
   Applications Applications Applications
        ↓          ↓          ↓
             Java ecosystem
```

Java is a **general-purpose programming language**, so it isn't restricted to only one type of software.

---

# 10. Slogan — WORA 🌎

Java's famous slogan is:

> **WORA — Write Once, Run Anywhere**

Imagine you write:

```java
System.out.println("Hello");
```

You compile it into **bytecode**.

That bytecode can be run on different operating systems using the appropriate JVM.

```text
             Java Source Code
                    ↓
                 Compiler
                    ↓
              Java Bytecode
                    ↓
          ┌─────────┼─────────┐
          ↓         ↓         ↓
       Windows     Linux     macOS
          ↓         ↓         ↓
         JVM       JVM       JVM
          ↓         ↓         ↓
        Run       Run       Run
```

That's the basic idea behind **WORA**.
