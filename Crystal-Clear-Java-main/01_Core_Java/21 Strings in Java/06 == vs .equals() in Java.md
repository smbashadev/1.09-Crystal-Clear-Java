# 🧒 `==` vs `.equals()` in Java

This is one of the **most important concepts when working with Strings**.

The easiest way to understand it is:

> **`==` asks: “Are these the same object?”**
> **`.equals()` asks: “Do these objects contain the same value?”**

---

## 1. `==` — Compares References

When we use:

```java
s1 == s2
```

Java checks whether `s1` and `s2` refer to the **same object**.

For Strings, beginners often call this **comparing addresses**.

A more accurate Java explanation is:

> `==` compares the **references** of two objects.

Think of two people holding address cards.

```text
s1 ───────┐
          ↓
       "Java"
          ↑
s2 ───────┘
```

Both references point to the same object.

Therefore:

```java
s1 == s2
```

is:

```text
true
```

---

# 2. `.equals()` — Compares Values

`.equals()` asks:

> **“Do these objects contain the same value/content?”**

For Strings, `.equals()` compares the characters.

For example:

```java
String s1 = "Java";
String s2 = "Java";

System.out.println(s1.equals(s2));
```

Both contain:

```text
Java
```

Therefore:

```text
true
```

---

# 3. Same Values, Different Objects

This is where the concept becomes important.

Look at:

```java
String s1 = new String("Java");
String s2 = new String("Java");
```

Both contain:

```text
Java
```

But `new` creates **two separate String objects**.

Conceptually:

```text
s1 ─────→ "Java"  ← Object 1

s2 ─────→ "Java"  ← Object 2
```

The values are the same:

```text
"Java"
"Java"
```

But the objects are different.

---

# 4. Using `==`

```java
class EqualsDemo {

    public static void main(String[] args) {

        String s1 = new String("Java");
        String s2 = new String("Java");

        System.out.println(s1 == s2);
    }
}
```

### Output

```text
false
```

Why?

Because:

```text
s1 → Object 1
s2 → Object 2
```

They are **different objects**.

So:

```java
s1 == s2
```

asks:

> “Are you pointing to the same object?”

Answer:

```text
❌ No → false
```

---

# 5. Using `.equals()`

Now change the program:

```java
class EqualsDemo {

    public static void main(String[] args) {

        String s1 = new String("Java");
        String s2 = new String("Java");

        System.out.println(s1.equals(s2));
    }
}
```

### Output

```text
true
```

Why?

Because `.equals()` checks the String contents:

```text
s1 → "Java"

s2 → "Java"
```

The contents are identical.

Therefore:

```text
✅ Same value → true
```

---

# 6. The Most Important Example

```java
class ComparisonDemo {

    public static void main(String[] args) {

        String s1 = new String("Java");
        String s2 = new String("Java");

        System.out.println(s1 == s2);
        System.out.println(s1.equals(s2));
    }
}
```

### Output

```text
false
true
```

### Why?

| Comparison      | What is checked?           | Result  |
| --------------- | -------------------------- | ------- |
| `s1 == s2`      | Same reference/object?     | `false` |
| `s1.equals(s2)` | Same String value/content? | `true`  |

---

# 7. Simple Real-World Example

Imagine two books.

### Book 1

```text
Java
```

### Book 2

```text
Java
```

They have the **same title**, but they are two different physical books.

```text
Book 1 → Java
Book 2 → Java
```

### `==`

Asks:

> “Are these the exact same physical book?”

❌ No.

### `.equals()`

Asks:

> “Do these books have the same content/value according to the equality definition?”

For Strings:

✅ Yes, they contain the same text.

---

# 8. String Pool Example

Now consider:

```java
String s1 = "Java";
String s2 = "Java";
```

Because both are the same String literal, Java can reuse the same pooled String.

Conceptually:

```text
       String Pool

          "Java"
         ↗      ↖
       s1        s2
```

Therefore:

```java
System.out.println(s1 == s2);
```

can produce:

```text
true
```

And:

```java
System.out.println(s1.equals(s2));
```

also produces:

```text
true
```

So:

```text
==       → true
.equals  → true
```

# 9. Compare Pool and `new`

This example is extremely useful:

```java
class StringComparison {

    public static void main(String[] args) {

        String s1 = "Java";
        String s2 = "Java";

        String s3 = new String("Java");
        String s4 = new String("Java");

        System.out.println(s1 == s2);
        System.out.println(s3 == s4);

        System.out.println(s1.equals(s3));
        System.out.println(s3.equals(s4));
    }
}
```

### Output

```text
true
false
true
true
```

### Understand each one

#### ①

```java
s1 == s2
```

Both can refer to the same pooled String.

```text
true
```

#### ②

```java
s3 == s4
```

Two `new` operations create separate objects.

```text
false
```

#### ③

```java
s1.equals(s3)
```

Both contain:

```text
Java
```

```text
true
```

#### ④

```java
s3.equals(s4)
```

Both contain:

```text
Java
```

```text
true
```

# 10. Your Four Important Points

## `==` compares addresses

For objects, `==` compares whether the two references refer to the **same object**.

Beginner memory:

> **`==` → same address/reference?**

---

## `.equals()` compares values

For String objects, `.equals()` compares their **contents**.

> **`.equals()` → same text/value?**

---

## Same values

Example:

```text
s1 → "Java"
s2 → "Java"
```

Both have the same value.

So:

```java
s1.equals(s2)
```

returns:

```text
true
```

---

## Different addresses

Example:

```text
s1 → Object 1 → "Java"

s2 → Object 2 → "Java"
```

Same value:

```text
Java
```

Different objects/references.

Therefore:

```java
s1 == s2
```

returns:

```text
false
```

---

# ⚠️ Very Common Beginner Mistake

Don't normally use:

```java
if (name1 == name2)
```

when your intention is:

> “Do these two Strings contain the same text?”

Instead use:

```java
if (name1.equals(name2))
```

Example:

```java
String name1 = new String("Basha");
String name2 = new String("Basha");

System.out.println(name1 == name2);
System.out.println(name1.equals(name2));
```

Output:

```text
false
true
```

# 🧠 Remember Forever

Think of two boxes:

```text
Box 1 → "JAVA"
Box 2 → "JAVA"
```

### `==`

Looks at the **boxes**:

```text
Are these the SAME box?
```

❌ No.

### `.equals()`

Looks at the **contents**:

```text
Do both boxes contain the SAME text?
```

✅ Yes.

So:

```text
       == 
        ↓
 SAME OBJECT?
        ↓
   Reference

     .equals()
        ↓
 SAME VALUE?
        ↓
   Content
```

## ⭐ Golden Rule

> **For Java objects, `==` compares references; for `String`, `.equals()` compares the String contents.**

And the classic example:

```java
String s1 = new String("Java");
String s2 = new String("Java");

System.out.println(s1 == s2);       // false
System.out.println(s1.equals(s2));  // true
```

**Different objects + same value = `==` false, `.equals()` true.**
