## 📌 About This Section

`01_Core_Java` is the **Core Java foundation** section of the [`Crystal-Clear-Java`](https://github.com/shaikbasha-dev/Crystal-Clear-Java) repository.

It is organized as a progressive learning path — starting with Java fundamentals and program flow, moving through memory, data types, methods, objects, strings, OOP concepts, inheritance, polymorphism, abstraction, and interfaces.

The material combines:

* 📖 Concept explanations
* 🧒 Beginner-friendly explanations
* 💻 Java programs and examples
* 🧠 Important rules and relationships
* 🎯 OOP-focused concepts
* 🔍 Interview-oriented topics

---

## 🎯 Learning Objectives

By completing this section, you will build a strong foundation in:

* Java fundamentals and program execution
* JDK, JRE, JVM, and JVM internal components
* Computer memory concepts relevant to Java execution
* Data types and type casting
* Input handling and decision-making
* Methods and method overloading
* Objects, reference variables, and instance variables
* Constructors and constructor chaining/overloading
* Strings and built-in String methods
* Static members and execution order
* Arrays
* The four major OOP pillars
* Encapsulation and controlled access
* Inheritance and inheritance types
* `super` and `this`
* Runtime polymorphism and method overriding
* Access specifiers
* `final`
* Has-A relationships
* Abstract classes and abstract methods
* Interfaces and interface-based polymorphism
* Marker interfaces and modern interface methods
