## 📖 About

A structured **Java Advanced Concepts** learning module focused on writing reliable, concurrent, and production-oriented Java applications.

## 📂 Modules

| Module                        | Focus                                                                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 🛡️ **01 Exception Handling** | Exceptions, error handling, `try-catch-finally`, `throw`, `throws`, custom exceptions, exception propagation      |
| 🧵 **02 Multithreading**      | Threads, `Runnable`, lifecycle, synchronization, locking, deadlock, Producer–Consumer, inter-thread communication |

### 🛡️ Exception Handling

* Checked & unchecked exceptions
* Exception hierarchy

* Nested `try-catch`
* `throw` & `throws`
* Exception propagation
* Method overriding exception rules
* Custom exceptions
* `StackOverflowError`

### 🧵 Multithreading

* Thread creation
* `Thread` & `Runnable`
* Thread lifecycle
* Thread names & `join()`
* Daemon threads
* Synchronization
* Synchronized methods & blocks
* Resource locking
* Deadlock
* Producer–Consumer problem
* `wait()` & `notify()`
